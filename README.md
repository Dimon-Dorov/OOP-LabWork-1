# Лабораторна робота № 1
## Структури в C++

**Виконав:** Доровских Д. О.  
**Дисципліна:** Об'єктно-орієнтоване програмування

### Порядок виконання роботи

*Структурою-Парою* називається структура із двома полями, які звичайно мають імена first і second.  
Потрібно реалізувати тип даних за допомогою такої структури. У всіх завданнях обов'язково повинні бути присутні:

* метод ініціалізації init(), метод повинен контролювати значення аргументів на коректність;
* метод введення з клавіатури Read();
* метод виведення на екран Display().

**Лінійне рівняння $y = Ax + B$**
